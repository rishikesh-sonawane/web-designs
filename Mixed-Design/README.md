# STONE — Architectural Residences

Luxury architectural residences designed to endure. A concept project exploring Quiet Luxury, Swiss Editorial, and Architectural Minimalism in web design.

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Leaflet (maps)
- Google Fonts (Cormorant Garamond + Inter)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project Structure

- `app/` — Pages and layouts
- `components/` — Reusable UI components
- `data/` — Property data
- `public/architecture/` — Architecture photography

## Design Tokens

- Bone: `#1A1A1A` (dark background)
- Charcoal: `#F9F8F6` (light text)
- Bronze: `#9E9A93` (muted metadata)
- Moss: `#A8B5A4` (accent)
