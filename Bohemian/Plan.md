* avoid layout shifts

* nature

**Typography → Color → Photography → Texture → Composition → Materiality → Motion → Interaction → Storytelling.**

Not from decorative objects.

The final website should make someone think:

> **“This brand has a soul.”**

Not:

> **“This is a website with leaves and beige colors.”**
