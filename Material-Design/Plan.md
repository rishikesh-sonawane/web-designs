# MASTER PROMPT — MATERIAL DESIGN PORTFOLIO UPGRADE

## ROLE

Act as a **Senior Product Designer + Creative Director + UX/UI Director + Frontend Engineer + Motion Designer + Design Systems Specialist + Web Performance Engineer**.

You are upgrading an existing website project called:

**Material-Design**

This is one of the final portfolio projects for a premium digital studio.

The objective is NOT to simply make the existing website "more beautiful."

Your objective is to transform the current prototype into a **portfolio-grade, commercially believable, exceptionally polished SaaS/product website** that makes a prospective client think:

> "This person understands professional product design, frontend development, interaction design, responsive design, and the details that separate an average website from a premium one."

The final result should feel like a real, funded SaaS/product company website — not a design-system demo, coding experiment, template, or AI-generated website.

# 21. MOTION TIMING

Use short, responsive transitions for interface controls.

General direction:

* microinteraction: ~120–200ms
* button/state transition: ~150–250ms
* component transition: ~200–350ms
* larger section transition: ~400–700ms

Do not rigidly follow these numbers if the visual result is worse.

Tune by perception.

Avoid animations that make the interface feel slow.

---

# 22. EASING

Do NOT use the same `ease` everywhere.

Use easing according to interaction.

For example:

* quick UI feedback → responsive ease-out
* entering content → smooth ease-out
* physical interaction → spring-like motion
* large cinematic movement → controlled custom easing

Motion should feel intentional.

Avoid exaggerated elastic/bouncy animation in the professional SaaS interface.

---

# 23. SCROLL REVEALS

Use scroll reveals selectively.

Good:

* heading fades/up slightly
* image reveals
* card groups stagger
* dashboard elements progressively appear

Bad:

* every paragraph animates
* every icon spins
* entire sections fly from random directions
* excessive stagger

A section should generally feel like one composition.

# 36. ANIMATION PERFORMANCE

For animations, prioritize properties that are cheap to animate:

* transform
* opacity

Avoid repeatedly animating:

* width
* height
* top
* left
* layout-affecting properties

Avoid unnecessary:

* expensive filters
* giant blur effects
* huge box-shadow animations
* continuous canvas rendering

Use `will-change` sparingly and only where justified.

Do not put `will-change` on everything.

If JavaScript-driven animation is necessary, use an efficient animation loop/library rather than creating uncontrolled scroll handlers.
